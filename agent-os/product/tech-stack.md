# Tech Stack

## Framework & Runtime

- **Application Framework:** SvelteKit
- **Language/Runtime:** Node.js
- **Package Manager:** pnpm

## Frontend

- **JavaScript Framework:** Svelte, vanilla JS
- **CSS Framework:** pico css, pure custom CSS/SCSS

## Search Backend

- **Search Engine:** Typesense (client-side queries)
- **Data Source:** pyf.aggregator (provides package data)

## Testing & Quality

- **Test Framework:** Playwright, vitest
- **Linting/Formatting:** ESLint, Prettier

## Deployment & Infrastructure

- **CI/CD:** GitHub Actions
