# Product Roadmap

## Phase 1: MVP

- **Package search** - Search packages by name, description, keywords
- **Version filtering** - Filter by Plone version compatibility
- **Package details** - View package info, versions, links, GitHub stats
- **Type filtering** - Filter by package type (addon, theme, integration)
- **Sorting** - Sort results by Title or Last modified date
- **Show release date**: Sho release date in details page version list.

## Phase 2: Post-Launch

- **Index Plone related packages from npmjs.com**: Since modern Plone frontends are built in JavaScript/TypeScript, we should include npm packages as well.
