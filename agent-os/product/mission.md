# Product Mission

## Problem

Finding quality Plone add-ons and packages is challenging. There is no centralized, searchable source for Plone package information, and discovering packages compatible with specific Plone versions requires significant effort. PyPI contains Plone packages but they are buried among millions of unrelated packages.

## Target Users

- **Plone developers** building sites who need add-ons
- **Plone integrators** evaluating packages for client projects
- **Plone community members** exploring the ecosystem
- **Package authors** wanting visibility for their packages

## Solution

pyf-gui is a dedicated Plone Add-on Gallery that exclusively shows Plone-related packages, dramatically increasing their visibility compared to PyPI. The solution combines:

- **Aggregated data** from PyPI with Plone-specific metadata
- **Typesense-powered instant search** with faceted filtering
- **Modern SvelteKit UI** providing a fast, clean browsing experience
- **GitHub stats and download metrics** to help users assess if packages are actively maintained
